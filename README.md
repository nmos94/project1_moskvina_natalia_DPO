# Лабиринт сокровищ

Текстовая приключенческая игра на Python, где игрок исследует лабиринт,
решает загадки и ищет сокровища.

## Описание

**Лабиринт сокровищ** — это интерактивная текстовая игра, в которой вы
играете роль искателя приключений, исследующего древний лабиринт. Ваша
цель — найти сокровище, спрятанное в секретной комнате.

### Особенности игры

- **8 уникальных комнат** для исследования
- **Система загадок** — решайте головоломки для получения наград
- **Инвентарь** — собирайте предметы и используйте их
- **Случайные события** — каждое прохождение уникально
- **Ловушки** — будьте осторожны при перемещении
- **Два пути к победе** — найдите ключ или взломайте код
- **Система рангов** — получите оценку вашего мастерства

### Игровой мир

Лабиринт состоит из следующих локаций:
- **Entrance** — тёмный вход, отправная точка путешествия
- **Hall** — большой зал с эхом и загадкой
- **Trap Room** — опасная комната с ловушками
- **Library** — пыльная библиотека с древними свитками
- **Armory** — оружейная с мечом и загадочной шкатулкой
- **Treasure Room** — комната сокровищ (требуется ключ)
- **Secret Garden** — скрытый садик с редкими предметами
- **Dungeon Corridor** — мрачный коридор с загадкой

## Как играть

### Основные команды

- `look` — осмотреть текущую комнату
- `go <direction>` — перейти в направлении (north/south/east/west)
- `north`, `south`, `east`, `west` — быстрое перемещение
- `take <item>` — поднять предмет
- `use <item>` — использовать предмет из инвентаря
- `inventory` (или `inv`) — показать инвентарь
- `solve` — попытаться решить загадку в комнате
- `help` — показать список команд
- `quit` (или `exit`) — выйти из игры

### Советы для прохождения

1. **Используйте факел** — он поможет избежать ловушек в тёмных комнатах
2. **Открывайте шкатулки** — внутри могут быть важные предметы
3. **Решайте загадки** — они дают награды и открывают новые пути
4. **Исследуйте все комнаты** — ключи могут быть где угодно
5. **Меч даёт защиту** — с ним случайные события менее опасны

### Пути к победе

Есть два способа открыть сундук с сокровищами:

1. **Найти treasure_key** в библиотеке
2. **Взломать код** — решите загадку сундука

Чем меньше шагов вы сделаете, тем выше будет ваш ранг!

## Демонстрация

### Видео прохождения игры

В репозитории находится файл `demo.cast` с записью полного прохождения игры
от запуска до победы.

Для воспроизведения демонстрации:

```bash
# Установите asciinema (если еще не установлен)
brew install asciinema  # macOS
# или
pip install asciinema   # Linux/Windows

# Воспроизведите запись
asciinema play demo.cast
```

### Быстрое прохождение

Для демонстрации также доступен скрипт автоматического прохождения:

```bash
./demo_script.sh
```

Этот скрипт показывает оптимальный путь к победе:
1. Взять факел в entrance
2. Решить загадку в hall (получить золотой медальон)
3. Найти treasure_key в library
4. Открыть treasure_room с ключом
5. Открыть сундук и победить!

### Архитектура

- **game_state** — центральное хранилище состояния игры
- **ROOMS** — словарь с описанием всех комнат
- **process_command()** — диспетчер команд (использует match/case)
- **pseudo_random()** — детерминированная генерация случайных событий
